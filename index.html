One calm shelf for every model you own

If you 3D print, your models are scattered across downloads, project folders, and external drives. Poly Shelf lets you browse them all — while leaving every original file exactly where it is.

🖼️

Rich previews

Thumbnails rendered straight from geometry with SceneKit, plus embedded previews, GCODE & Blender extraction, and QuickLook fallback.

⚡

Fast search

Full-text search across file names, tags, and metadata — powered by SQLite FTS5, so results are instant even in large libraries.

🏷️

Tagging, manual and AI

Auto-tag by format and folder, tag by hand, or generate tags with any OpenAI-compatible endpoint you point it at.

👁️

Live folder watching

FSEvents keeps your library in sync as files are added, changed, or renamed — no manual rescans needed.

🧬

Find duplicates

Content-hash comparison finds identical models stored in different places, so you can finally see what you actually have.

📦

Import / export metadata

Your tags and metadata travel with you — export and re-import them at any time, without touching the source files.

● Read-only by design

Your files are never at risk

Poly Shelf opens your folders with the macOS sandbox entitlement com.apple.security.files.user-selected.read-only — so writes to your model folders fail at the operating system level, not just by convention.

Any code path that obtains a writable handle to a file inside a watched folder is treated as a bug, and every build can be verified with a snapshot-and-diff script against a real test corpus. 

$ scripts/verify-nondestructive.sh snapshot ~/models
# … exercise the app fully …
$ scripts/verify-nondestructive.sh verify ~/models
✔ 4,812 files checked — nothing moved,
  nothing renamed, nothing modified.

Up and running in a minute

Download

Grab PolyShelf-vX.Y.Z.zip from the latest release.

Install

Unzip and drag Poly Shelf.app into your /Applications folder.

First launch

The app is ad-hoc signed, so Gatekeeper will warn once. Right-click → Open, confirm, and you're in.

If macOS still blocks it, clear the quarantine flag: xattr -dr com.apple.quarantine "/Applications/Poly Shelf.app"

Stop hunting through folders.

Point Poly Shelf at your model folders and get a searchable, tagged, previewed library — with zero risk to your files.

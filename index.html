Poly Shelf GitHub ↗

A library for every model you've ever downloaded.

Poly Shelf is a native macOS app for people who 3D print. Point it at the folders you already have — it indexes, previews, tags, and searches thousands of STL, 3MF, OBJ, STEP, and GCODE files. And it never writes a byte back.

Download for macOS View the source

Free & open source · macOS 14 or later

What it does

Previews from geometry

Thumbnails rendered from the mesh itself — not the filename.

Instant search

Full-text across names, tags, and notes. Fast at thousands of files.

Tags, auto or AI

By format, by folder, by hand — or from any OpenAI-compatible endpoint.

Always in sync

Folders are watched live. Rename a file in Finder; the shelf follows.

Duplicates, found

Content hashing spots the same model across folders and drives.

Metadata that travels

Export tags and notes, re-import anywhere. Sources untouched.

The inspector

Select a model and Poly Shelf tells you what it is: real dimensions in millimeters, triangle count, format, size — read from the geometry, not the filename.
